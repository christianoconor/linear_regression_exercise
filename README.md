# linear_regression_exercise
This project was a study in linear regression methods using a large, multi-featured dataset.

This study utilized scikit-learn’s linear regression and loss functions to analyse a dataset of free-falling spheres made from materials like iron, titanium, and polycarbonate. The dataset included density, mass, radius, temperature, pressure, height, and time of fall. After cleaning, analyses examined feature correlations, compared loss functions, and assessed gradient descent efficiency. Model validity was tested against an analytical model, revealing insights into material behaviour and regression performance. The study underscored the importance of data preprocessing and method selection for accurate predictive modelling.

This project was also my first encounter with homo- and heteroscedasticity as measures of how well a model can extrapolate data.
